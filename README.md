# cloude

Минималистичное тёмное приложение со входом по почте и паролю.

- **Astro** — оболочка: страницы, маршруты, сервер
- **Svelte** — интерактивные «острова» внутри страниц (форма входа, кнопка выхода)
- **Better Auth** — регистрация, вход, сессии
- **Cloudflare Workers + D1** — хостинг и база данных, деплой через Wrangler CLI

Сайт: https://cloude.suprik24.workers.dev

## Локальный запуск

> В PowerShell на Windows вместо `npm` пиши `npm.cmd` (там по умолчанию запрещены `.ps1`-скрипты).

1. `npm install` — скачать библиотеки (заодно ставит защиту от коммитов в `main`)
2. Скопировать `.dev.vars.example` в `.dev.vars` и заполнить `BETTER_AUTH_SECRET` (команда для генерации — внутри файла)
3. `npm run db:migrate:local` — создать таблицы в локальной базе
4. `npm run dev` — открыть http://localhost:4321

## Правила работы

- В `main` напрямую не коммитим — только через ветку и Pull Request.
- GitHub Actions проверяет каждый Pull Request (типы + сборка), а после влития в `main` сам выкладывает сайт на Cloudflare.
- Dependabot раз в неделю сам открывает Pull Request'ы с обновлениями: один для GitHub Actions (`actions`), один для мелких обновлений JS-библиотек (`js`) и по отдельному на каждое крупное (major) обновление. Зелёная галочка робота — можно вливать; красный крестик — обновление что-то ломает, не вливать.

## Скиллы для Claude

В `.claude/skills/` лежат скиллы из [mattpocock/skills](https://github.com/mattpocock/skills), скопированные без изменений:

- `code-review` — ревью Pull Request'а по двум осям: соответствие правилам проекта (Standards) и заданию (Spec). Перед влитием PR проси Claude пройтись по нему этим скиллом. Если скилл предложит запустить `/setup-matt-pocock-skills` — это можно игнорировать.
- `grill-me` (+ `grilling`, без которого он не работает) — Claude задаёт вопросы раундами, чтобы проверить план, когда непонятно, как что-то сделать. Сам Claude его не запускает — набери `/grill-me`.
