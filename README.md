# cloude

Минималистичное тёмное приложение со входом по почте и паролю.

- **Astro** — оболочка: страницы, маршруты, сервер
- **Svelte** — интерактивные «острова» внутри страниц (форма входа, кнопка выхода)
- **Better Auth** — регистрация, вход, сессии
- **Cloudflare Workers + D1** — хостинг и база данных, деплой через Wrangler CLI

Сайт: https://cloude.suprik24.workers.dev

## Локальный запуск

> В PowerShell на Windows вместо `npm` пиши `npm.cmd` (там по умолчанию запрещены `.ps1`-скрипты).

1. `npm install` — скачать библиотеки (заодно ставит защиту от коммитов в `main`)
2. Скопировать `.dev.vars.example` в `.dev.vars` и заполнить `BETTER_AUTH_SECRET` (команда для генерации — внутри файла)
3. `npm run db:migrate:local` — создать таблицы в локальной базе
4. `npm run dev` — открыть http://localhost:4321

## Правила работы

- В `main` напрямую не коммитим — только через ветку и Pull Request.
- GitHub Actions проверяет каждый Pull Request (типы + сборка), а после влития в `main` сам выкладывает сайт на Cloudflare.
